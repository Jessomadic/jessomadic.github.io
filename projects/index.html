Internal system built from scratch

Custom Ticketing & POS Operations System

  • Python
  • JavaScript
  • Microsoft SQL Server
  • POS Integration
  • Legacy System Replacement

The legacy Perl/PHP system still handled tickets, labor, pricing, parts, and custom-computer builds, but it had become impossible to update or repair and still ran as an IIS application on Windows Server 2008. I learned the workflow, then designed, built, and deployed its replacement from scratch in Python and JavaScript with Microsoft SQL Server and existing POS integration. It fully retired the old system while preserving full backward compatibility, so all existing data remained usable in the new system. I still own authentication, backups, updates, bug fixes, and feature development.

  • RMM
  • Windows Endpoints
  • TCP/IP
  • Monitoring
